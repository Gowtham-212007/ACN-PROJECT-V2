# springer_cicps_submission — CICPS 2027 (Springer LNCS) manuscript

Status: **provisionally formatted, NOT ready to submit** until the unresolved author items in SUBMISSION_CHECKLIST.md are filled.

## Build
```
cd springer_cicps_submission
python3 build_main.py        # regenerates main.tex from ../papers/ieee/IEEE_ACCESS_FINAL.tex + new sections (optional; main.tex is committed)
export TEXINPUTS=.:
pdflatex main && bibtex main && pdflatex main && pdflatex main
```
Requires TeX Live with `llncs` (included here: llncs.cls v2.26, splncs04.bst), `algorithm`, `algpseudocode`, `booktabs`, `amsmath`, `graphicx`. Result: `main.pdf`, 15 pages including references (limit 15; see checklist).
