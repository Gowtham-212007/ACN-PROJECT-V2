# v1: original course project (archived)

The first version of the project: Kernel PCA with five classifiers on a 1,000-row stratified sample of three CIC-IDS2017 day files (11 classes), 45 experiments (3 test sizes x 3 KPCA settings x 5 classifiers), one script and one result image per run.

This is not the paper's experiment and none of the paper's numbers come from here. The paper uses the 6,000-record, 15-class sample and the pipeline in `../src/acn/`. Scripts here were written to run from the repository root of that earlier version and are kept for reference, not maintained.
